# 阶段一：数据发现与底座契约 (Data Discovery)

本文件是 RDHS 度量体系的**数据输入与底表唯一性契约**，解决“数据从哪来、分母是谁、如何清洗”的根本问题。

---

## 一、 核心铁律：实时在线直连，严禁读取死缓存

- **必须实时在线**：诊断的目标是掌握产品与业务线**此时此刻最新的产研真实进展**。
- **严禁读本地缓存**：默认严禁读取本地 `runtime/`、`data/` 下的历史静态 JSON/CSV 文件。读取历史快照会导致把月初开局数据误判为现状，丧失体检诊断价值。
- **鉴权失效即时自愈**：若 CLI 返回 `AUTH_REQUIRED`，优先执行 `meegle auth login` 刷新登录凭据，绝不悄悄回退到死缓存。

---

## 二、 飞书项目数据源参数与获取契约

### 1. 核心参数
| 配置项 | 标识 / ID | 说明 |
|---|---|---|
| `project_key` | `cbg_product_develop` | 飞书项目空间标识（CBG产研空间） |
| 本月 Chart ID | `7659618575337915254` | 【本月】产研健康度得分(RDHS) By 产品 |
| 上月 Chart ID | `7681204196376314742` | 【上月】产研健康度得分(RDHS) By 产品（结算基线） |
| 产品型号工作项类型 | `693f665435b354b7ca0085dc` | 产品型号/子平台（主数据底表类型） |

### 2. CLI 命令标准
```bash
# 获取本月实时图表
meegle chart get --project-key cbg_product_develop --chart-id 7659618575337915254 --format json

# 获取上月图表（用于环比对比）
meegle chart get --project-key cbg_product_develop --chart-id 7681204196376314742 --format json
```

### 3. 指标动态解析防线（严禁硬编码数字索引）
必须先读取返回的 `data.quota_titles: string[]` 列表，用 `quota_titles.indexOf("指标名称")` 动态取对应列：
- 综合分：`RDHS(100')`
- 五组件：`链路闭环得分(25')`、`交付闭环得分(15')`、`时效节奏合理性(20')`、`颗粒度对齐度(20')`、`质量敏锐度(20')`
- 过程指标：`有效参与人数`、`人均需求吞吐量`、`人均缺陷关闭量`、`需求交付周期`、`需求开发周期`、`严重缺陷占比`、`低级缺陷占比`、`应发布需求数`、`有效发布需求数`、`需求总量`、`积压需求占比`

## 三、 官方主数据清洗三大铁律（对齐 RDHS Reports 核心引擎）

### 1. 工作流状态过滤
仅纳管产品型号/子平台工作项状态等于 **`In Progress`（研发中）** 的记录。
（状态为 `started 待审核`、`rOjOjH7U_ 生命周期维护`、`Finished 已结束` 的工作项直接排除）。

### 2. 交付定制属性排除（核心防线）
在产品型号/子平台工作项中，检查【产品属性】字段（`field_22acd7`）：
- 选项枚举：`标准产品`（`ettrf_vl8`） / `交付定制`（`hmeckpgbh`）
- **凡属性为【交付定制】（`hmeckpgbh`）的工作项，必须在底表阶段直接排除，绝不计入 RDHS 考核与达标率分母！**
- 线上共排除了 **19 款**交付定制产品（AI文娱 9款、讯飞听见 5款、开放平台 4款、AI翻译 1款）。

### 3. 测试业务线排除
排除 `业务线 == "测试业务线"` 的记录（2款）。

---

## 四、 动态纳管与过滤原则（无须维护死名单）

产品清单随业务发展动态增减，**严禁在技能内维护静态写死的产品名单**，统一按以下线上动态规则实时筛选：

1. **自动从实时图表中提取**：从 `chart get` 返回的数据中，动态提取当前业务线/全空间下所有出现的产品行；
2. **剔除交付定制属性**：主数据中产品属性为【交付定制】（`hmeckpgbh`）的记录直接过滤，不计入自研考核分母；
3. **剔除测试业务线**：`业务线 == "测试业务线"` 的记录自动排除；
4. **实时主数据对齐**：凡是主数据处于“研发中（In Progress）”的标准自研产品，自动纳管进考核分母。

---

## 五、 未度量产品纳管规则
- 主数据在研且属性为标准产品、但在当期 Chart 中匹配不到或全部指标全为 0（`is_zero_spec == true`）的产品，**必须强制纳管计入分母**；
- 统一归入：**治理分档=重点治理**，**优先级=P0**，**RDHS得分=—（未形成有效度量）**，**主问题标签=过程数据缺失**。
