# RDHS 产研健康度极速诊断与治理 (meegle-rdhs-diagnosis)

本技能直接直连飞书项目线上度量底表，实时获取产品及全业务线**此时此刻最真实、最新的产研健康状况 (RDHS)**，定位瓶颈病根并给出极简提分抓手。

---

## ⚡️ 极速执行法则（首选专属脚本，严禁多轮低效抓取）

为防止拉取 900+ 行图表造成大体积 JSON 截断、网络往返超时与多轮手写解析脚本，**必须优先执行本技能内置的高性能脚本 `scripts/rdhs_query.py`**，单命令秒级出具完整体检报告：

```bash
# 1. 单品实时诊断（含五维得分、过程指标、7阶归因病根、极简提分建议）
python3 <skill-dir>/scripts/rdhs_query.py --product "产品名称"

# 2. 单品环比体检（自动对比上月基线，计算 Δ 分值变化）
python3 <skill-dir>/scripts/rdhs_query.py --product "产品名称" --compare

# 3. 产线 / 业务线全景诊断榜单（支持 一级 或 二级业务线名称，如: "AI交互"、"录音笔"）
python3 <skill-dir>/scripts/rdhs_query.py --business-line "业务线名称" [--compare]

# 4. 全 BG 大盘排行榜（跨全部业务线）
python3 <skill-dir>/scripts/rdhs_query.py --all

# 5. 会话短缓存说明：默认实时直连 (0缓存)。若短时间高频分析同一底表可指定 --cache-ttl 300
python3 <skill-dir>/scripts/rdhs_query.py --product "产品名称" --cache-ttl 300
```

*注：`<skill-dir>` 解析为本 SKILL.md 所在目录的绝对路径。*

## 核心判定准则（内联速查，免读外链）

### 1. 四级治理分档
- **< 45 分（重点治理 P0）**：严重过程脱节、数据断层或重度积压，接口人必须介入整改；
- **45 ~ 59.9 分（风险改进 P1）**：核心流程通畅，但存在单项突出短板（如积压率高、严重缺陷超标）；
- **60 ~ 69.9 分（持续优化 P2）**：准及格，各项基本功规范，聚焦时效节奏微调以冲刺达标；
- **≥ 70 分（常规跟踪 达标）**：达到健康基准线，常规监控指标稳定性。

### 2. 7 阶归因判定树（按优先级自上而下匹配）
1. `有效参与人数 == 0` ➔ **【过程数据缺失】**（提卡未挂实际责任人，规划失序）
2. `人均吞吐 == 0 或 链路得分 < 15` ➔ **【价值链路不完整】**（人均缺陷>0为只修Bug未交需求，吞吐与缺陷均为0为无计划研发，交付断链）
3. `积压需求占比 > 30%` ➔ **【需求积压】**（僵尸需求超期在途滞留，在途失控）
4. `严重缺陷占比 > 15%` ➔ **【质量管理风险】**（严重致命缺陷超标，质量失守）
5. `交付闭环得分 < 8` ➔ **【发布闭环不足】**（发版未挂发布计划，发版脱节）
6. `时效节奏合理性 < 10` ➔ **【研发节奏偏慢】**（在途超长或排期停滞，周期失控）
7. `其他` ➔ **【过程能力优化】**（各单项指标基本健全，拆解粗糙）
*注：若主问题非【需求积压】，但积压占比 > 30%，显式追加“叠加积压风险”。*

### 3. 五维组件健康标尺（得分率 = 实际得分 / 满分）
- 得分率 $\ge 80\%$：**🟢 优秀 / 正常**
- $50\% \le$ 得分率 $< 80\%$：**🟡 中游 / 偏低**
- 得分率 $< 50\%$：**🔴 严重偏低 / 缺失**

## 异常自愈与三段式回退表（Failure Mechanisms & Fallback）

| 触发条件 | 一线自动修复动作 | 仍失败最终兜底方案 |
|---|---|---|
| **API 频控触发 (10429)** | 脚本内置指数退避机制自动等待 1.5s/3.0s 重试 | 提示用户稍候 5 秒，改用 `--cache-ttl 60` 避免瞬间脉冲请求 |
| **登录凭证失效 (AUTH_REQUIRED)** | 终端提示认证过期并指引运行 `meegle auth login` | 完成扫码登录后重新发起诊断指令 |
| **产品名在图表中未命中** | 脚本自动模糊匹配主数据并检查别名/型号 | 检查主数据是否未纳管或未进入研发中，按未度量(P0)纳入 |
| **网络请求超时或中断** | 脚本单次自动重试 1 次 | 提示检查内网网络环境或 VPN 连接状态 |
