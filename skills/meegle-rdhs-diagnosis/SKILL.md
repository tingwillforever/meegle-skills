# RDHS 产研健康度诊断与行动建议 (meegle-rdhs-diagnosis)

本技能通过官方原生的 `meegle` 命令行工具，**直接从飞书项目线上拉取当期最新的实时度量数据**。
**核心定位**：服务于没有编程背景的业务负责人与管理层，随时掌握各产品及全业务线**此时此刻最真实、最新的产研健康状况**，并以直白懂人话的方式定位短板、给出具体管理抓手。

---

## 核心工作原则（铁律）

### 1. 强制实时在线获取（实时第一，严禁读死缓存）
- **核心铁律**：**必须始终调用 `meegle chart get` 直连飞书项目拉取最新的实时图表数据**！
- **严禁静默读缓存**：绝对禁止默认去读本地历史静态文件（如 `runtime/`、`data/` 下的历史快照等）。读死缓存会把月初开局数据当成现状，彻底失去诊断时效性。
- **登录失效即时自愈**：如果 CLI 报错提示未登录（`AUTH_REQUIRED`），**必须立即执行或指引执行 `meegle auth login` 完成登录认证**，拿到最新数据；**绝对禁止**因为认证失败而悄悄退回读取本地过期文件！

### 2. 老板懂人话视角（通俗落地，拒绝黑话）
- 面向没有编程背景的业务主管与决策者；
- 所有技术概念与计算过程一律转化为通俗的业务语言（例如：不说“RPC接口/微服务/流水线挂载”，说“团队干活交活闭环、上线有没有走正规发布登记、手里压没压陈年旧债”）；
- 输出聚焦于“现状多少分、差几分及格、团队具体哪一步卡住了、下周找谁做哪一个动作”。

## 核心数据拉取契约（实时获取）

| 配置项 | 标识 / ID | 说明 |
|---|---|---|
| `project_key` | `cbg_product_develop` | 飞书项目空间标识（CBG产研空间） |
| **【本月最新】Chart ID** | `7659618575337915254` | **线上最新实时图表**：实时计算当期产研健康度 |
| **【上月基线】Chart ID** | `7681204196376314742` | 上月结算基线：用于环比对比进展 |

### CLI 实时调用命令
```bash
# 1. 检查/拉取当月最新实时图表（必须首选）
meegle chart get --project-key cbg_product_develop --chart-id 7659618575337915254 --format json

# 2. 拉取上月基线图表（用于对比进步/退步）
meegle chart get --project-key cbg_product_develop --chart-id 7681204196376314742 --format json

# 3. 若遇登录失效，执行登录后重试
meegle auth login
```

## 标准输出规范

输出格式遵循 `references/4-improvement-governance.md` 定义：
- **单品体检报告**：输出《产品 RDHS 产研过程诊断报告》（总分评级 ＋ 环比变化 ＋ 五维体检表 ＋ 老板关注事实 ＋ 跨过70分极简提分动作 ＋ 团队自检清单）；
- **全盘排行榜**：输出《业务线 / 全 BG 产研健康度排行榜》（达标率、四级评级分布、各业务线落后短板与关键管理抓手）；
- **指标答疑**：输出《指标白话速查卡》（大白话通俗含义 ＋ 测团队什么 ＋ 扣分雷区 ＋ 拿高分动作）。
